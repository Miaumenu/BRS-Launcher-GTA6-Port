# Suporte

Antes de pedir ajuda, consulte:

- `docs/hardware-compatibility.md` para requisitos e resultados medidos;
- `docs/debugging-gpu-hangs.md` para coletar diagnóstico;
- `docs/architecture.md` para localizar a responsabilidade de cada crate.

Relate uma falha reproduzível pelo formulário de issue correspondente. Para dúvidas de desenvolvimento, abra uma discussão ou issue com versão, sistema, GPU e etapas observadas. Não envie arquivos do jogo, dumps, credenciais ou logs sem sanitização.
