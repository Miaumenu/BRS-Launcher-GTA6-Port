# Relatórios de hardware

Envie uma contribuição por PR ou use o formulário de issue de hardware. Os relatórios são identificados pela GPU e pelo cenário, não por uma pasta permanente de cada pessoa. A autoria pode ser informada no conteúdo se o testador quiser.

Preencha `_TEMPLATE.md`, registre a versão/commit, driver, Windows, capacidades consultadas e resultado. Anexe só trechos sanitizados. A equipe atualiza `docs/hardware-compatibility.md` após revisar as evidências.
