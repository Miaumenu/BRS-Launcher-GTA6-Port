# Código de conduta

Esperamos comunicação respeitosa, objetiva e focada no trabalho. Critique ideias e resultados com evidências; não ataque pessoas. Mantenha discussões técnicas acessíveis, dê contexto suficiente para reproduzir problemas e aceite correções de boa-fé.

Assédio, ameaças, discriminação, exposição de dados privados e sabotagem deliberada não são aceitos. A equipe de manutenção pode moderar issues, discussões e contribuições para preservar um espaço seguro e útil.

Para relatar um problema de conduta, contate a equipe responsável pelo repositório em privado pelo GitHub.
