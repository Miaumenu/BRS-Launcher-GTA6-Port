# Relato de segurança

Não publique vulnerabilidades exploráveis, tokens, chaves, credenciais ou dados pessoais em issues públicas. Use o recurso privado de relato de vulnerabilidade do GitHub, se estiver habilitado para este repositório; caso contrário, contate a conta mantenedora do repositório em privado.

Informe a versão/commit afetado, impacto, passos mínimos de reprodução e uma correção sugerida quando possível. Não anexe arquivos do jogo ou dumps proprietários.
